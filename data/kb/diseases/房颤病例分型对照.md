# 房颤病例分型对照 — 同样"心悸胸闷气短"，严重度天差地别

> 说明：本文档基于两组真实住院病例**彻底脱敏**提炼（不保留姓名、病案号、住址等任何身份信息），
> 用于导诊系统对"主诉相同但严重度不同"的判别训练，非诊疗依据。

## 一、核心洞察

"心悸、胸闷、气短"是房颤最常见的三个主诉，但**同样的症状，背后的严重度和处理方式可能完全不同**。
导诊系统不能只看症状词，必须结合**年龄、合并疾病、心功能、病程**来区分轻症和重症。

## 二、病例对照（脱敏后）

| 维度 | 病例A（年轻、阵发性） | 病例B（高龄、持续性） |
|---|---|---|
| 年龄/性别 | 49岁 女性 | 68岁 女性 |
| 主诉 | 发作性心悸胸闷气短6年，加重2月 | 心悸胸闷气短 |
| 房颤类型 | 阵发性（情绪激动/劳累诱发，休息可缓解） | 持续性 |
| 合并疾病 | 高血压（1级很高危）、脂肪肝 | 高血压、冠心病、心衰、陈旧性脑梗 |
| 心功能 | 左室收缩功能正常 | 左室收缩功能受损（心衰） |
| 器质损害 | 轻（左房左室略增大、轻度瓣膜返流） | 重（多病共存） |
| 治疗方向 | 可考虑射频消融（环肺静脉前庭），有望根治 | 长期药物管理、抗凝、控制心衰 |
| 危险度 | 相对低危，但需评估卒中风险 | 高危，栓塞与心衰风险高 |

## 三、判别要点（导诊系统应如何区分）

- **年轻 + 阵发性 + 心功能正常 + 无冠心病心衰** → 偏轻，重点评估是否适合射频消融，挂心内科门诊。
- **高龄 + 持续性 + 合并心衰/冠心病/脑梗** → 偏重，需规范抗凝 + 控制心衰，警惕卒中，必要时急诊。
- **共同红线**：无论哪种，一旦出现"胸痛、呼吸困难、晕厥、一侧肢体无力、言语不清"→ 立即急诊（心梗/心衰/卒中风险）。

## 四、为什么要区分

- 阵发性房颤若早识别、早消融，部分患者可根治，避免进展为持续性房颤。
- 持续性房颤合并心衰、脑梗者，若漏判危险度，可能延误抗凝，导致卒中。
- 这是"症状相同、处置完全不同"的典型场景，是导诊系统最需要长进的判别能力。
