# 病例C：中老年女性三踝骨折（骨科创伤）

> 说明：本文档基于真实住院病历**彻底脱敏**提炼，隐去姓名、病案号、登记号、住址、联系人等一切身份信息，仅保留年龄、性别、主诉、检查与诊断，用于导诊知识检索，非诊疗依据。

## 患者画像（脱敏）
- 年龄/性别：56 岁，女性。
- 主诉：摔伤致右下肢疼痛伴活动受限 3 小时。
- 起病：3 小时前摔倒，无意识丧失、无头痛头晕、无恶心呕吐、无胸闷气短。

## 关键检查结果
- X 线（右侧踝关节，前后位 + 侧位）：右侧内踝、外踝、后踝骨折，周围软组织肿胀。

## 诊断
1. 三踝骨折（右）
2. 踝关节损伤（右）
3. 肺诊断性影像异常（双肺上叶多发结节）
4. 脂肪肝
5. 下肢韧带损伤（踝关节，右）

## 体格检查要点
- 右足背、外踝及小腿下段外侧可见多处陈旧性瘢痕（形态不规则，部分呈手术切口样改变）。
- 外踝处瘢痕轻微凹陷，切口远端见米粒大小溃疡创面，干燥、无明显渗出。
- 体温 36.5℃，脉搏 108 次/分，血压 158/103 mmHg。

## 导诊判别要点（这个病例教会我们什么）
- **明确外伤史（摔倒）+ 受伤部位疼痛 + 活动受限** → 高度提示骨折，应直接去骨科或急诊，不要当作普通扭伤在家观察。
- "三踝骨折"（内踝 + 外踝 + 后踝同时骨折）是踝关节严重骨折，多需手术治疗。
- 中老年摔倒后踝关节疼痛、不能活动，即使没有明显畸形，也应拍 X 线排除隐匿骨折。

## 就诊建议
- 摔倒/外伤后，伤处疼痛、肿胀、不能活动或变形 → 挂骨科，或直接急诊。
- 怀疑骨折时，先固定制动、避免自行揉捏或强行活动，尽快拍 X 线。
- 若同时有意识不清、头痛呕吐（尤其头部外伤）→ 需急诊排查颅内损伤。
