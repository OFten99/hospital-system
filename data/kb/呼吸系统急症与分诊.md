# 呼吸系统急症与分诊（呼吸内科）

> 来源：腾讯医典（慢阻肺、哮喘、呼吸急促词条）、深圳市人民医院肺栓塞案例等公开权威资料。

## 一、三大致命呼吸急症（最该守住的底线）

### 1. 肺栓塞（PE）——「会装的杀手」
- 血栓（多来自**下肢深静脉**）脱落，顺血流堵住肺动脉，可致右心衰竭、休克、猝死。
- 高危：久坐不动、长途旅行、长期卧床、骨折/手术后、肿瘤、孕产妇、肥胖。
- **三个关键信号**：
  1. 突然胸痛（深呼吸/咳嗽时加重）
  2. 突然气促、呼吸困难，伴心慌、出冷汗
  3. 头晕甚至晕厥（胸痛气促后晕厥=危重）
- 年轻人也会中招，勿归因于「太累」。

### 2. 急性呼吸衰竭 / 慢阻肺急性加重（AECOPD）
- 慢阻肺患者急性加重可危及生命，典型表现：咳痰量增多、痰变黄变黏、气短胸闷加重、发热>38℃、口唇/指端发绀、意识模糊或嗜睡。
- **立即就医信号**：窒息、中重度呼吸困难（说不了完整句子）、剧烈胸痛、咳大量鲜红血。

### 3. 哮喘急性发作
- 诱因：过敏原、运动、感染、药物、情绪等，夜间常加重。
- 若按既定用药后仍不缓解、呼吸困难加重、咳深褐/带血痰 → 立即急诊（可能呼吸衰竭）。

## 二、咯血 / 胸痛 / 呼吸困难的鉴别线索

| 症状组合 | 提示 |
|---|---|
| 咳粉红色泡沫痰 + 呼吸困难 + 下肢水肿 | 心力衰竭（转心内科/急诊） |
| 持续咳嗽咳痰 + 咯血 | 肺炎、肺结核、肺癌 |
| 突发胸痛 + 气促 + 晕厥 | 肺栓塞（急诊） |
| 反复喘息 + 夜间/过敏加重 | 哮喘 |
| 慢性咳嗽咳痰 + 活动后气短 + 吸烟史 | 慢阻肺 |

## 三、立即拨打 120 的红旗信号

- 窒息、无法说完整句子、活动即重度呼吸困难
- 剧烈胸痛或胸痛急剧加重
- 咳大量鲜红色血
- 突发胸痛/气促伴晕厥（警惕肺栓塞）
- 口唇、指端明显发绀

## 四、分诊判别要点（导诊系统用）

- 单纯「咳嗽、发热、流涕」→ 呼吸内科门诊，不急。
- 「胸痛 + 气促 + 晕厥」或「咯血量大」→ **肺栓塞/大咯血，立即急诊**，这是呼吸科最危险的两类。
- 慢阻肺/哮喘老病人「急性加重 + 发绀 + 说不了整句」→ 急诊。
- 「咳粉红泡沫痰 + 端坐呼吸 + 下肢水肿」→ 心衰，按心血管急症处理（急诊）。
- 慢性咳嗽 > 8 周、痰中带血丝、消瘦 → 呼吸内科门诊排查（结核/肿瘤），不算急诊但需尽快。
