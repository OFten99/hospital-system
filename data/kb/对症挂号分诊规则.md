# 对症挂号分诊规则 — 什么症状挂什么科

> 说明：本文档根据公开的对症挂号指南整理，用于导诊系统的科室映射规则，非诊疗依据。

## 一、心血管系统（胸闷/心悸/水肿/血压）

- 心悸、胸闷气短、紫绀、血压高或低、脉搏异常、活动后心慌气短 → 心血管内科。
- 高血压、冠心病、心律失常、心力衰竭 → 心血管内科。
- 需要手术：心脏瓣膜病需置换、先天性心脏病、胸主动脉夹层 → 心脏外科。
- 腹主动脉夹层、周围血管疾病 → 血管外科。

## 二、呼吸系统（咳嗽/胸痛/呼吸困难）

- 感冒咳嗽、肺炎、支气管炎、发热伴咳嗽咳痰胸痛 → 呼吸内科。
- 咯血、胸部肿瘤、食道疾病、肋骨骨折 → 胸外科（心胸外科）。
- 大量胸腔积液、肺脓肿、肺癌需手术、严重气胸 → 心胸外科。

## 三、消化系统（腹痛/反酸/黄疸/呕吐）

- 胃炎、肠炎、肝炎、反酸烧心、胃痛腹胀、腹泻腹痛、吞咽困难 → 消化内科。
- 喜欢按着腹部的腹痛 → 消化内科；拒绝按压腹部 → 普外科。
- 呕血便血伴休克、突发剧烈腹痛伴板状腹、急性阑尾炎、肠梗阻、胆囊结石嵌顿 → 立即转普外科（急诊）。
- 便血鲜红色 → 普外科；暗红或黑色 → 消化内科。

## 四、神经系统（头痛/麻木/眩晕/瘫痪）

- 脑梗、癫痫、帕金森、头痛头晕、面瘫、瘫痪、肌无力、抽搐、眩晕 → 神经内科。
- 脑出血需手术、脑/脊髓肿瘤、三叉神经痛介入 → 神经外科。
- 头痛伴视力障碍 → 神经外科。
- 发热伴头痛、恶心、神志改变 → 神经内科。

## 五、泌尿系统（尿痛/血尿/肾区痛）

- 肾炎、肾病综合征、尿频尿急尿痛、尿少伴浮肿 → 肾内科（肾脏内科）。
- 血尿、肾/输尿管结石>0.6cm、前列腺增生排尿困难、泌尿系肿瘤 → 泌尿外科。
- 腰腹痛伴小便异常 → 泌尿外科。

## 六、内分泌代谢（多饮/消瘦/肥胖/浮肿）

- 糖尿病、甲亢、痛风、肥胖、消瘦、生长发育异常、血糖高 → 内分泌科。
- 浮肿伴怕冷、嗜睡、脱发 → 内分泌科。
- 甲状腺结节 TI-RADS 4类以上、肾上腺肿瘤 → 转外科。

## 七、骨骼肌肉（关节痛/骨折/腰腿痛）

- 骨折、脱位、关节置换、脊柱侧弯 → 骨科。
- 韧带损伤、半月板撕裂 → 运动医学科。
- 多发性关节痛 → 风湿免疫科；单发性关节痛 → 骨科。
- 腰腿痛 → 脊柱外科/骨科。

## 八、发热的细分（关键判别）

- 发热伴咳嗽、咳痰、胸痛 → 呼吸内科。
- 发热伴腹泻、腹胀、腹痛 → 感染科。
- 发热伴头痛、恶心、神志改变 → 神经内科。
- 发热伴关节疼痛 → 风湿免疫科。

## 九、浮肿的细分（关键判别）

- 脸肿为主伴尿少 → 肾脏内科。
- 腹胀为主伴黄疸 → 消化内科。
- 下肢肿为主伴气促 → 心内科。
- 伴怕冷、嗜睡、脱发 → 内分泌科。

## 十、其他专科

- 14岁以下儿童（除眼耳鼻喉皮肤外）→ 儿科。
- 月经异常、白带异常、阴道出血、下腹包块 → 妇科。
- 围产期保健、分娩 → 产科。
- 眼科、耳鼻喉、口腔、皮肤、中医、职业病等专科疾病，症状部位明确，直接挂对应专科。

## 十一、紧急转诊总原则（优先级最高，先判断）

出现以下情况，无论原计划挂什么科，一律先转急诊：突发剧烈疼痛、意识不清、大出血、呼吸困难、持续高热（>39℃）。
