# 心血管疾病危险分层 — 房颤卒中风险与高血压分级

> 说明：本文档根据公开的权威指南（CHA₂DS₂-VASc 评分、高血压分级）整理，用于导诊系统对心血管疾病严重程度的判别，非诊疗依据。

## 一、房颤卒中风险评估（CHA₂DS₂-VASc 评分）

用于判断房颤患者发生脑卒中（中风）的风险，决定是否需要抗凝治疗。

| 危险因素 | 分值 |
|---|---|
| C：充血性心力衰竭/左心室功能不全 | 1 |
| H：高血压 | 1 |
| A：年龄 ≥ 75 岁 | 2 |
| D：糖尿病 | 1 |
| S：卒中/TIA/血栓栓塞史 | 2 |
| V：血管疾病（冠心病、心梗、外周动脉病） | 1 |
| A：年龄 65~74 岁 | 1 |
| Sc：女性 | 1 |

**结果判读：**
- 总分 = 0 分 → 低风险，通常无需抗凝。
- 总分 = 1 分 → 中风险，可考虑抗凝。
- 总分 ≥ 2 分 → 高风险，推荐口服抗凝治疗（如利伐沙班、华法林等）。

## 二、高血压分级（成人）

| 类别 | 收缩压 mmHg | 舒张压 mmHg |
|---|---|---|
| 正常血压 | < 120 | 且 < 80 |
| 正常高值 | 120~139 | 和/或 80~89 |
| 1级高血压（轻度） | 140~159 | 和/或 90~99 |
| 2级高血压（中度） | 160~179 | 和/或 100~109 |
| 3级高血压（重度） | ≥ 180 | 和/或 ≥ 110 |

**危险分层提示：** 高血压 + 房颤是常见组合，血压控制不佳会显著增加房颤发作和卒中风险。

## 三、房颤的危险信号（哪些要重视）

- 心悸伴胸痛/胸部压迫感、呼吸困难、恶心呕吐 → 可能心脏病发作，立即就医。
- 突发视力改变、说不清话、一侧肢体无力/麻木 → 脑卒中（中风）发作，立即就医。
- 无诱因突发晕倒、头晕眼花、意识混乱 → 及时就医。
- 房颤患者未抗凝，卒中风险显著升高。

## 四、房颤的常见治疗方向

- 抗凝：预防血栓、降低卒中（华法林需监测 INR 维持 2.0~3.0；或新型口服抗凝药 NOAC）。
- 控制心率：美托洛尔、维拉帕米、地高辛等。
- 恢复窦律：普罗帕酮、胺碘酮等；或电复律。
- 导管射频消融术：通过高频电流消除房颤病灶（如环肺静脉前庭隔离），恢复窦性心律。
