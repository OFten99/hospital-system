主评测集（165 条，照词表构造）上 LLM 与纯规则持平，是因为规则本就没漏词；
这批 25 条是规则**真漏了**的句子，LLM 的增量在这里才显现出来。

## 三、LLM 也纠正不了的样本（增量的天花板）

所以补不出任何词。这暴露的是**词表覆盖的边界**，不是 LLM 的能力问题——
想让系统处理这些，得先扩词表，模型凭空抽不出来的。

## 五、延迟与降级

| 指标 | 数值 |

| LLM 平均延迟 | 730 ms |
| LLM P95 延迟 | 930 ms |
| 降级条数 | 0 |

延迟是上线决策的硬约束：挂号窗口等不了 1 秒。所以 LLM 抽取层默认关闭，只在规则 low 时兜底，而不是每条都过模型。

## 六、这套数字的边界（诚实声明）

1. 这批 25 条仍是**人工构造**的口语，不是真实门诊日志，只能说明覆盖了哪些口语缺口，不能直接外推到真实挂号量。
2. 标注是单人完成，gold 存在争议空间（如「奶水不够孩子吃不饱」是产后缺乳还是儿科问题）。
3. LLM 补词受 `LLM_ADDED_WEIGHT=0.4` 打折，只纠正那些「规则完全漏词」的句子，不会和规则精确命中的词平权——这是防幻觉的关键设计，也限定了它的作用场景。
